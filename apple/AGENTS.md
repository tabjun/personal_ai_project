# Apple Project Boundary

Read `../AGENTS.md` and `../tools/isolation/README.md` first.
Work only inside `apple/` on `apple` or `feature/apple/*`.
The user chose one checkout: finish outstanding work before switching projects.
All folders share the root branch; never force checkout or auto-stash. Never stage stock,
resume, legacy quantitative_trading or root files in an apple feature commit.
Keep apple dependencies, tests, environments, history and results here.
Merge direction: apple feature -> apple (if applicable) -> develop -> main.
Never merge resume/stock/develop/main into apple to prepare a workspace.
Repository-wide governance changes require a separate explicit request.
