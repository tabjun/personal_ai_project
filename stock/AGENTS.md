# Stock Project Boundary

Read `../AGENTS.md` and `../tools/isolation/README.md` first.
Work only inside `stock/` or the server-used `quantitative_trading/` on `stock` or `feature/stock/*`.
The user chose one checkout: finish outstanding work before switching projects.
All folders share the root branch; never force checkout or auto-stash. Never stage apple,
resume or root files in a stock feature commit.
Keep stock dependencies, tests, environments, history and results here.
Merge direction: stock feature -> stock (if applicable) -> develop -> main.
Never merge resume/apple/develop/main into stock to prepare a workspace.
Repository-wide governance changes require a separate explicit request.
