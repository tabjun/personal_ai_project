    Linux/macOS: 공식 uv 설치 안내에 따라 설치하고 압축을 푼 폴더의 터미널에서 같은 명령을 실행합니다. 설치된 Chrome/Edge가 없으면 uv run playwright install chromium도 실행합니다. Linux 시스템 의존성 설치는 관리자 정책을 확인하세요.

연결이 안 되면 본인 PC의 도구 실행 여부·포트·팝업 차단·명령의 허용 웹 주소를 확인하세요. HTTPS나 사이트 보안 경고를 무시하지 마세요. 연결이 제한되는 브라우저에서는 표준 이력서를 다운로드해 로컬 화면에 업로드하는 방법을 사용하세요.
회사 자체 채용 사이트는 회사 양식 변환을 사용할 수 있습니다. 로그인·2차 인증과 최종 입력/저장은 현재 수동입니다. 사이트별 인증 우회나 세션 파일 수동 업로드는 제공하지 않습니다.

  3. 양식 변환을 눌러 연결된 항목·미작성 항목·길이 제한을 확인합니다.

공개 웹에서 본인 PC로 연결

        
  1. PC에서 연결 도구 ZIP을 다운로드하고 우클릭 → 모두 압축 풀기로 새 폴더에 풉니다.
  2. Windows는 Start-Resume-Connector.cmd를 더블클릭합니다. uv 설치 질문이 나오면 직접 선택하세요. PowerShell/Linux/macOS 수동 실행 안내는 플랫폼 연결의 접힌 안내에 있습니다.
  3. 실행 창의 로컬 주소를 입력하고 이력서 전달에 동의한 뒤 내 PC 연결 창을 엽니다. 사용 중 실행 창을 닫지 마세요.
  4. 로컬 창에서 출처·이력서를 확인하고 가져오기를 승인합니다. 다시 검수한 뒤 전용 브라우저에서 로그인·2차 인증을 직접 완료합니다. 비밀번호·쿠키를 웹에 올리지 않습니다.

        
아래 사진은 가상 이력서의 실제 전달 과정입니다. 휴대폰만으로 무설치 자동 저장을 제공하지 않습니다.

        
      

      

        
외부 웹에서는 먼저 플랫폼 연결에서 본인 PC의 연결 도구를 실행하세요. 로그인·2차 인증은 그 PC의 전용 사이트 브라우저에서 직접 완료합니다. 운영자 노트북의 로그인 세션은 사용하지 않습니다.

        
기존 채용사이트 이력서의 선택 항목 저장하기
