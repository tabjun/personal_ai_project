## 2026-10-07 작성 범위

사용자 지정 외부 취업 폴더를 조사하고, 공통 정리 폴더의 최신 경력 이력서·경력기술서·경험기술서·공용 자기소개서·CV·기존 이력서 총 6개 DOCX를 읽었다. 전체 파일을 모두 읽었다고 주장하지 않는다. 주민등록·금융자료·근로계약·중복본·강의 참고자료는 작성 근거에서 제외했다.

명시 선택 원본의 SHA256과 문단 번호를 로컬 corpus에 기록했다. 최신 경력 문서를 우선하고, 과거 자료로 연구·산학 프로젝트·학력·수상·자격을 보강했다. 제품화 전 단계, 특허 출원 등 원문의 한정 조건을 유지하고, 검증 조건이 불명확한 성능 수치는 공통 소개에서 제외했다. 이메일이 문서별로 달라 사이트 기존 연락처는 유지했다. 재직 형태는 사용자가 직접 정규직이라고 확인했다.

8개 검수 블록: 제목, 소개, 재직 경력, 부서, 학력, 연구/산학 프로젝트, 수상/자격, 공통 자기소개서. 개인 산출물은 ignored `result/master_resume/`에만 보관한다. 공통 패키지의 모든 필드가 각 사이트에 자동 매핑되었다는 뜻은 아니다.

## 구현과 검증 경계

- 실제 로그인된 브라우저 편집은 브라우저 도구 Playwright locator로 수행했다. Python 전용 프로필의 CLI가 동일한 로그인 세션으로 실행된 것은 아니다.
- `job_agent/documents/library.py`는 원본 중복 제거, 원본 변경·추출문 변조 감지, 필드별 원문 참조 유효성을 검사한다. 문장 의미의 사실성 판단은 사람이 원문과 비교해야 한다.
- 실제 최신 원본과 검수된 master package를 사용한 로컬 Chromium 통합 테스트 포함 12개 통과. 로컬 fixture 검증과 실사이트 저장 검증을 구분한다.
- 최종 저장/개인정보 동의/작성완료/지원은 사용자 검수 후 수동 처리한다. 인증·연락처·희망조건·공개 범위를 임의 변경하지 않았다.

```powershell
$env:RESUME_TEST_DOCX = '<최신 원본.docx>'
$env:RESUME_MASTER_PACKAGE = 'result/master_resume/master_resume.json'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
